# Сцены с областью видимости наблюдателей

Сценовый runtime Vega заменяет полезную часть TerraZ FakeProvider. Он накладывает
неизменяемые тайловые слои для конкретных `WorldId` и наблюдателей, но не подменяет
`Terraria.Main.tile`: каноническим состоянием мира по-прежнему владеет Terraria.

Каждая сцена имеет явного владельца и `ISceneLease`. Освобождение lease удаляет все
слои владельца и ставит затронутые области на перерисовку. Порядок слоя задаётся явно;
при одинаковом порядке выигрывает созданный позже слой, а пересечения показываются как
конфликты в Operations. Область наблюдения бывает общей или персональной.

Встроенные потребители `Vega.Modules.Scenes` закрывают проверенные сценарии TerraZ:

- предпросмотр clipboard/mask WorldEdit переиспользует identity слоя при перемещении и
  изменении размера и очищается вместе с сессией владельца;
- Region-Vision рисует персональную границу, а действия по фантомным тайлам отклоняет
  то же правило наблюдателя;
- LobbyVisuals поддерживает общие и персональные кадры UI/анимации;
- FakeProviderClustering владеет слоями видимости игроков, NPC и снарядов.

Исходящие квадраты тайлов собираются отдельно для получателя. После штатной отправки
секции Vega ограниченно перерисовывает пересекающиеся слои. Видимость entity одинакова
для адресной и широковещательной отправки; входящие действия со скрытыми NPC и
снарядами отклоняются через типизированные views Multiplicity. Очередь ограничена 256
областями, один пакет — максимум 46x46 тайлов (даже максимальный размер заголовков/полей помещается в длину пакета). Владельцы, конфликты, dirty regions, visibility
layers и ошибки адаптера видны в Operations/TUI.

## Базовая производительность

Запуск: `dotnet run --project benchmarks/Vega.Scene.Benchmarks -c Release`. На x64,
.NET 10.0.11 синтетическая нагрузка из 64 слоёв дала:

| Нагрузка | Результат | Managed allocation |
| --- | ---: | ---: |
| 250 000 поисков среди 64 слоёв | 1,18 мкс/операцию | 56 Б всего |
| композиция области 64x64 | 2,14 мс всего | 56 Б всего |
| 1 000 замен набора из 200 наблюдателей | 27,1 мкс/операцию | 13,0 МБ всего |
| создание 1 000 персональных слоёв 32x32 с общими immutable-тайлами | 2,69 мкс/операцию | 1,36 МБ всего |

Это регрессионная база, а не гарантия для любого железа. Harness также выполняет
перемещение WorldEdit preview с mask и churn композиции лобби на 200 наблюдателей и
300 entity; CI запускает эти нагрузки как регрессионный gate и выводит время и managed
allocation. Пропускную способность сокетов с реальными клиентами измеряют на этапе
deployment qualification, а не используют как незакрытый implementation gate. Горячий
поиск тайла не создаёт LINQ-объекты на каждый вызов, а мониторинг использует только
периодические bounded snapshots.

Многомировой runtime в одном процессе намеренно не является частью этого API. В фазе
17 активный мир получает отдельный процесс; менять решение можно только после
доказанной изоляции глобального состояния Terraria.

## Встроенный FakeProvider

`Vega.Modules.Scenes.FakeProviderService` — нативный аналог именованных глобальных и персональных провайдеров из FakeProvider. Он использует существующий runtime сцен Vega и не загружает TShock/TSAPI DLL. Имена уникальны в пределах мира, регистр не учитывается. Персональный наблюдатель удаляется при закрытии соединения, а при освобождении модуля удаляются все принадлежащие ему провайдеры.

Команды (разрешение `vega.scenes.manage`, модуль Scenes):

```text
fake create <имя> <x> <y> <ширина> <высота> [air|stone]
pfake create <имя> <онлайн-игрок> <x> <y> <ширина> <высота> [air|stone]
fake|pfake list [страница]
fake|pfake info <имя>
fake|pfake move <имя> <dx> <dy>
fake|pfake layer <имя> <слой>
fake|pfake enable|disable|remove <имя>
```

По умолчанию заполнение — воздух. Командное создание ограничено 255x255. API также принимает произвольные неизменяемые `SceneTileArea`, позволяет менять содержимое и размеры (`ReplaceTiles`), набор наблюдателей и порядок слоёв. Плагины по-прежнему могут владеть собственными слоями через `context.World.Scenes`.

Это визуальные слои, а не замена `Main.tile`, отдельная физическая симуляция или виртуальные сундуки/tile entities. Входящие взаимодействия с фантомными тайлами блокируются. Полноценные песочницы по-прежнему изолированы процессами. В горячем пути поиск использует лениво обновляемый неизменяемый список по миру и приоритету без блокировки на каждом тайле; множества наблюдателей защищены от внешних изменений. Нет дополнительной плотной карты индексов по размеру целого мира.
Для 8+ слоёв индекс использует разреженные чанки 64x64 только там, где есть провайдеры; число ссылок ограничено, при превышении используется отсортированный список. Повторный ABBA (64 слоя): 1406–1432 → 294–322 нс на lookup; 64x64 624–634 → 350–372 нс/тайл. Массовая замена observer sets пока дороже. [Перфоманс-отчёт](../performance-2026-11-26.md).
Для сторонних плагинов используйте штатный `context.World.FakeProvider` (см. [Plugin SDK](plugin-sdk.md#fakeprovider-для-плагинов)); не требуется подключать Vega.Modules.Scenes как библиотеку или использовать fake-команды. Персональные leases привязаны к сессиям и освобождаются при hot reload.
