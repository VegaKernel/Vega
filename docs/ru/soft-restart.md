# Мягкий перезапуск внутри процесса

Vega умеет пересоздать встроенные прикладные модули, не выгружая Terraria и не завершая серверный процесс. Это административный инструмент восстановления, по умолчанию он выключен. Он не делает безопасной горячую замену нативных библиотек или произвольных плагинов.

## Граница владения

| Время жизни | Компоненты | Поведение |
| --- | --- | --- |
| `PreservedInfrastructure` | Terraria/TerrariaRuntime, загруженный мир, listener и подключённые игроки, game-thread dispatcher, БД, аккаунты/сессии, баны, регионы, локализация, lifecycle, Operations/TUI, world image и бекапы | Продолжают работать и сохраняют авторитетное состояние. |
| `RestartableModule` | PVP, CustomItems, AutoWorldCleaner, Mentions, Chests, Wipe и Scenes | Пересоздаются явными фабриками. Пакеты, чат, chest callbacks, команды и статус проходят через маршрутизатор активного поколения. |
| `ProcessRestartOnly` | нативные/runtime-сборки, выбор listener/мира/хранилища, TerrariaRuntime hooks вне отслеживаемого модуля, невыгруженный или повреждённый `ServerPlugins` context | Требуют обычного перезапуска процесса; Vega не сообщает ложный успех. |

Временное состояние модулей сбрасывается. Для действительно необходимой непрерывности модуль может реализовать `IModuleRestartStateParticipant`: хост принимает не больше одного МиБ явно именованного состояния с совпавшей версией. Авторизация, модерация, регионы и мир в этом механизме не нуждаются — ими владеют сохраняемые сервисы.

## Конфигурация и команды

Файл `config/soft-restart.json`:

```json
{
  "enabled": false,
  "drainTimeoutSeconds": 5,
  "moduleTimeoutSeconds": 10,
  "totalTimeoutSeconds": 60
}
```

После включения до запуска процесса оператору с `vega.server.soft-restart` доступны:

```text
softrestart confirm
softrestart Pvp
restartmodules Chests Scenes
modules restart confirm
```

Цель проверяется по полному или короткому имени. Сейчас встроенные модули образуют одну единицу владения перезапуском, поэтому Vega пересоздаёт их проверенное dependency closure; запрошенные цели сохраняются в результате и аудите. Для перезапуска всех модулей обязательно слово `confirm`. Параллельный запрос получает `Busy`.

Vega заранее конструирует замену, закрывает callback gate, дожидается активной работы, останавливает старый граф в обратном порядке зависимостей, передаёт совместимое состояние, запускает замену в топологическом порядке и атомарно публикует её. При ошибке запуска выполняется одна попытка создать свежий rollback-граф. Ошибка rollback переводит систему в `Degraded` с закрытым gate — нужен перезапуск процесса.

Ход операции и итог публикуются структурированными событиями `soft-restart`, видимыми в обычной консоли и окне логов TUI. Для внешних collectible-плагинов остаются `plugin reload`/`plugin unload`. Грязный либо не собранный `ServerPlugins` context заставляет soft restart вернуть `ProcessRestartRequired`.

Нативные `exit`, `stop` и `shutdown` по-прежнему сохраняют мир и завершают Terraria. Порт/пароль listener, выбор мира, provider БД, обновление нативных сборок и смена режима `.vworld` требуют перезапуска процесса; замена загруженного мира выполняется отдельным world-reset flow.

Бенчмарк lifecycle:

```powershell
dotnet run --project benchmarks/Vega.SoftRestart.Benchmarks -c Release
```
