# Автосохранение и очистка мира

Файл `config/world-maintenance.json` управляет автосохранением сервера и опциональной
очисткой сущностей мира. Vega заменяет фиксированный таймер Terraria, поэтому одновременно
работает только одно расписание сохранений. Без изменения конфигурации мир автоматически
сохраняется каждые 10 минут. Если включён world image, после ручного и автоматического
сохранения также обновляется `.vworld`.

```json
{
  "autoSave": {
    "enabled": true,
    "intervalMinutes": 10
  },
  "cleanup": {
    "enabled": false,
    "intervalMinutes": 30,
    "onlyWhenPlayersOnline": true,
    "items": {
      "enabled": true,
      "minimumActiveCount": 200,
      "minimumAgeSeconds": 300
    },
    "projectiles": {
      "enabled": true,
      "minimumActiveCount": 700,
      "excludeMinions": true,
      "excludeSentries": true
    }
  }
}
```

Интервалы ограничиваются диапазоном 1–1440 минут. Предметы удаляются только после
достижения порога общего количества и только если они старше `minimumAgeSeconds`.
Снаряды очищаются после достижения отдельного порога. Миньоны и турели по умолчанию
не удаляются. Очистка выключена по умолчанию, потому что это политика конкретного сервера.

Проверка расписания и изменение массивов сущностей выполняются только в игровом потоке
Terraria. Запись автосохранения и сборка `.vworld` выполняются вне игрового потока по
стабильному snapshot с атомарной заменой image. Ошибки доступны в структурированных
категориях логов `world-maintenance` и `world-image`.
